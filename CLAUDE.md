# pattern-language-ui

Vue 3 + Vite front end for ruralpatternlanguage.com, deployed on Vercel. The API is the
sibling repo `pattern-language-service` (NestJS on Render), reached through `VITE_API_URL`.
The story verification work in progress is described in `pattern-language-service/HANDOFF.md`.

## Rules

- Every API field added recently is optional. Read new fields through a fallback so a page
  keeps rendering when the service is a deploy behind. A raw lookup that throws inside a
  template silently blanks every section below it.
- `src/utils/data/stories.research.ts` is generated by the service repo's
  `research/build_stories.py`. Do not edit it by hand. `src/utils/data/stories.ts` is a hand
  copy of the service's seed file; keep the two in sync when either changes.
- `scripts/prerender.ts` runs as `postbuild` and writes static HTML plus the sitemap for every
  route it knows. When a page or story is added, add it there too, and keep the router's meta
  in sync with the prerender pages array.
- The design is Geist only, no serif fonts. Headings stand alone, with no small uppercase
  label above them. No em dashes in copy.
- Do not create test data through the API; the database is the live beta.

## Commands

- Dev server: `npm run dev`
- Type-check: `npm run type-check`
- Build with prerender: `npm run build`
- Tests: `npm run test:unit` (Vitest), `npm run test:e2e` (Playwright, `e2e/`)

## Layout

- `src/views/`: route pages. `FullStoryPage.vue` loads one story.
- `src/components/full-story/`: hero, content, sidebar. `FullStoryContent.vue` renders the
  evidence block when `story.evidence` exists and the old references list otherwise.
- `src/types/index.ts`: shared types, including `StoryEvidence`, mirrored from the service.
- `src/services/api.ts`: API client. `storiesApi.search` uses `GET /stories?search=`.
- `src/stores/`: Pinia stores.
